# Cronometro – APK Android senza PC di sviluppo

1. Crea un account gratuito su github.com e un nuovo repository (anche privato).
2. Carica tutti i file di questa cartella nel repository, mantenendo la struttura
   (compresa la cartella nascosta `.github/workflows/build-apk.yml`).
3. Apri la scheda **Actions** → workflow **Build APK** → attendi il segno verde (5-8 minuti).
   Se non parte da solo: **Run workflow**.
4. Apri l'esecuzione completata → in fondo **Artifacts** → scarica `cronometro-apk` (è uno zip con `app-debug.apk`).
5. Copia l'APK sul telefono, aprilo e consenti "Installa app sconosciute" per il file manager/browser usato.
